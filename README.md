# c2py23

> All code in this repository was generated by [DeepSeek V4](https://deepseek.com)
> and other large language models, in collaboration with jonwright.

Wrap C99 functions as Python C extensions via the buffer protocol.
One compiled `.so` works on Python 2.7 through 3.15 with no recompilation.
Zero copies, zero allocations. No numpy required.

An f2py-style wrapper generator for C, with two additions:

- one binary per platform for every Python (the
  [nimpy](https://github.com/yglukhov/nimpy) trick: no libpython link,
  the CPython API is resolved at import);
- CPU-architecture variants (SSE2/AVX2/AVX-512, NEON, Altivec) selected
  at run time.

The C it wraps looks like Fortran: scalars and flat arrays owned by the
caller.  No structs, strings, callbacks, keyword arguments or allocation.
If you need those, or only target recent CPython, use something else 
instead.  See `docs/design.md`.

## Install

```bash
pip install c2py23
```

Requires a C99 compiler (gcc, clang, or MSVC on Windows).  No Python dependencies beyond stdlib.

## Quick Start

Create a C function:

```c
/* arraysum.c */
#include <stdint.h>
int array_sum(const double *a, const double *b, double *out, intptr_t n) {
    for (intptr_t i = 0; i < n; i++) out[i] = a[i] + b[i];
    return n;
}
```

Write the interface file:

```python
# arraysum.c2py
{
    "module": "arraysum",
    "source": ["arraysum.c"],
    "functions": [
        {
            "py_sig": "array_sum(a: buffer, b: buffer, out: buffer) -> int",
            "checks": [
                "b.n == a.n",
                "out.n >= a.n",
            ],
            "c_overloads": [
                {
                    "sig": "array_sum(const double *a, const double *b, double *out, intptr_t n) -> int",
                    "map": {
                        "a": "a.ptr",
                        "b": "b.ptr",
                        "out": "out.ptr",
                        "n": "a.n",
                    },
                },
            ],
        },
    ],
}
```

Build and use:

```bash
# Generate the wrapper and the single-header runtime (c2py.h) next to it
c2py23 arraysum.c2py -o arraysum_wrapper.c --emit-header

# Compile  --  no libpython, no include path
cc -O2 -shared -fPIC arraysum_wrapper.c arraysum.c -ldl -lm -o arraysum.so

python3 -c "
import ctypes
import arraysum
a = (ctypes.c_double * 4)(1, 2, 3, 4)
b = (ctypes.c_double * 4)(5, 6, 7, 8)
r = (ctypes.c_double * 4)()
arraysum.array_sum(a, b, r)
print(list(r))  # [6.0, 8.0, 10.0, 12.0]
"
```

The wrapper checks element type, alignment, contiguity and overlap of
writable buffers on every call.  It cannot know how far your C code reads
or writes: every output buffer needs a size check in `checks:`.  See
"Writing Safe .c2py Definitions" in `docs/user_guide.md`.

## Usage

```bash
c2py23 file.c2py -o wrapper.c       # generate C wrapper
c2py23 file.c2py                     # print to stdout
c2py23 --version                     # print version
c2py23 file.c2py -o wrapper.c --emit-header       # also emit c2py.h alongside the wrapper
c2py23 --regenerate-header                        # regenerate c2py.h from runtime sources

# Or via python -m:
python -m c2py23 file.c2py -o wrapper.c
```

See `c2py23/setuptools_helper.py` for `PythonhBuildExt` setuptools helper (pythonh mode only).

## Supported Platforms

Linux (x86_64, aarch64, gcc/clang/tcc/zig), macOS (aarch64, clang),
Windows (x64/i386, MSVC/MinGW). Free-threaded Python 3.13+ supported.

## Examples

The [GitHub repository](https://github.com/jonwright/c2py23) includes build examples
(not in the PyPI sdist):

- `examples/kissfft_wrap/`  --  real + complex FFT over float buffers
- `examples/lz4_wrap/`  --  compress/decompress over byte buffers
- `examples/simd_dispatch/`  --  CPU feature dispatch (SSE2/AVX2/AVX-512, NEON, Altivec)
- `examples/threading_bench/`  --  GIL release, free-threading, OpenMP
- `examples/wheel_demo/`  --  multi-platform wheel packaging
- `examples/cmake_demo/`, `examples/meson_demo/`  --  build system integration

## Status

Beta.  Built for the author's own production use
([c2ImageD11](https://github.com/jonwright/c2ImageD11),
[bslz4_to_sparse](https://github.com/jonwright/bslz4_to_sparse)).
Refuses to import on a Python newer than the last one audited (3.15).
Tested on 2.7, 3.6-3.15, 3.14t and 3.15t; reviews and the crashes they
found are in `archive/`.
